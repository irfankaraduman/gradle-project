This project contains sample Dart source files that demonstrate various security vulnerabilities
detectable by OpenText SAST (Fortify) Static Code Analyzer.

Project Structure:
------------------
dart-sample/
  - test_data_leak_in_logger_df.dart      : Demonstrates privacy violation through logging sensitive data
  - test_hardcoded_credentials_df.dart    : Demonstrates hardcoded password vulnerability
  - test_input_validation_df.dart         : Demonstrates privacy violation through unvalidated input
  - pubspec.yaml                          : Dart project metadata and configuration file
                                            Contains project name, description, SDK version constraints,
                                            and dependency declarations (similar to package.json in Node.js
                                            or requirements.txt in Python)
  - .dart_tool/package_config.json        : Generated by 'dart pub get' command
                                            Contains package resolution information including:
                                            - Package name and root URI mappings
                                            - Language version (Dart SDK version: 2.12)
                                            - Package URI paths for library resolution
                                            - Generator version (pub tool version: 3.9.3)
                                            Helps Fortify analyzer understand the project's package
                                            dependencies and resolve imports during static analysis


How to Run OpenText SAST (Fortify) Analysis:
---------------------------------------------

Type the following commands to run OpenText SAST (Fortify) on the Dart source files:

0. Setup Dart project dependencies (if not already done):
   $ cd dart-sample
   $ dart pub get
   $ cd ..

1. Clean the previous build (if any):
   $ sourceanalyzer -b dart-sample -clean

2. Translate the Dart source files:
   $ sourceanalyzer -b dart-sample dart-sample/test_data_leak_in_logger_df.dart dart-sample/test_hardcoded_credentials_df.dart dart-sample/test_input_validation_df.dart

   Alternatively, translate the entire directory:
   $ sourceanalyzer -b dart-sample dart-sample/

3. Scan and generate the analysis results file:
   $ sourceanalyzer -b dart-sample -scan -f dart-sample.fpr

Open the results dart-sample.fpr in Audit Workbench:

The analysis results should contain vulnerabilities in the following categories:
The first Privacy Violation vulnerability (test_data_leak_in_logger_df.dart) shows the tainted data from user input (stdin.readLineSync()) flows through a global variable, then through the User class constructor to a private field, and eventually to a print() function that logs the sensitive token.
The second Privacy Violation vulnerability (test_input_validation_df.dart) shows the tainted data from user input (stdin.readLineSync()) flows through a global variable to the CommentService class method parameter, and is then directly printed without any validation or sanitization.
The Password Management: Hardcoded Password vulnerability (test_hardcoded_credentials_df.dart) shows hardcoded credentials stored directly in the AuthService class as string literals.
The analysis results might include other issues depending on the version of the Rulepacks used in the scan.
